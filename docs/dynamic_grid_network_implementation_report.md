# 动态网格 Hybrid Q 网络实现报告

## 实现结果

已按确认方案完成动态网格改造。Grid/Hybrid 网络不再把空间特征固定池化到
10×10，而是直接使用 `--width`、`--height` 对应的实际 `H×W` 构建全连接层。

## 当前实现

- 全局分支为 `1×1 Conv 32→8 + GroupNorm + ReLU`，删除
  `AdaptiveAvgPool2d`、普通平均池化和 `_build_pool_layer()`。
- 动态计算全局维度 `8*H*W`；默认 3×3 局部分支为 72 维。
- 保留共享 CNN、独立全局/局部投影、可配置蛇头局部分支和 Dueling Q 头。
- 局部窗口默认 3×3，可通过 `--local-crop-size` 调整，也可通过 `--no-local-crop` 关闭。
- 局部裁剪使用展平后的直接索引和 `gather`，不再为所有棋盘位置生成 `unfold` 窗口。
- 删除 `cnn_pool_size` 配置、`--cnn-pool-size` 命令行参数及相关参数传递。
- checkpoint 架构版本升级为 3，不再保存池化目标尺寸。
- checkpoint 加载器只接受架构版本 3；同版本但缺少局部裁剪字段的历史 checkpoint
  按启用 5×5 局部分支加载，其他架构版本需要使用匹配的 Git 版本。
- `--deterministic` 现在使用严格确定性算法；遇到无确定性实现的算子会直接报错，
  关闭该参数时会显式恢复非确定性算法模式。
- README 已同步更新，说明当前动态网格架构和同版本历史 checkpoint 的兼容规则。

## 动态维度示例

| 网格 | 全局维度 | Hybrid 融合维度 |
|---|---:|---:|
| 6×6 | 288 | 380 |
| 10×10 | 800 | 892 |
| 20×20 | 3200 | 3292 |

不同尺寸会构建不同输入形状的全连接层，因此每种网格应使用独立 checkpoint。
本次实现不支持同一个模型在一次训练中混合不同宽高。

关闭局部分支时，Hybrid 融合维度为 `8*H*W+20`；使用其他局部窗口时，融合维度为
`8*H*W + 8*K² + 20`。
